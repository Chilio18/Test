# Revenue Intelligence Platform

AI-powered sales conversation analytics for **UnameIT** — a Gong alternative built on your existing technology stack.

## What it does

- **Conversation Capture**: Upload audio/video recordings of sales meetings
- **AI Transcription**: Automatic speech-to-text with speaker diarization
- **Conversation Intelligence**: AI-generated summaries, insights, action items, deal risks, and coaching scores
- **CRM Integration**: Sync insights to Zoho CRM or the internal UnameIT CRM
- **Deal Intelligence**: Health score, risk score, and confidence score per opportunity
- **Knowledge Search**: Ask natural language questions across all call transcripts (RAG)
- **Dashboards**: Leadership, manager, and rep-level performance views
- **Coaching**: Scorecards and coaching feedback generated by AI

## Architecture

| | Technology |
|---|---|
| Frontend | Nuxt 3 · Vue 3 · TypeScript · Tailwind CSS · Pinia |
| Backend | .NET 8 · Clean Architecture · CQRS · EF Core |
| Database | PostgreSQL 16 + pgvector |
| Cache / Queue | Redis + Hangfire |
| Storage | S3-compatible (MinIO for local dev) |
| AI | OpenAI GPT-4o · Anthropic Claude · Azure OpenAI |
| Auth | OIDC/OAuth2 (Entra ID · Google Workspace) |

Full architecture documentation: [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md)

## Quick Start

### Prerequisites
- Docker & Docker Compose
- .NET 8 SDK
- Node.js 22

### Local development

```bash
# 1. Copy environment config
cp .env.example .env
# Edit .env with your settings

# 2. Start infrastructure (Postgres, Redis, MinIO, Seq)
docker compose -f docker-compose.dev.yml up -d

# 3. Start backend API
cd backend
dotnet run --project src/UnameIT.RevenueIntelligence.API

# 4. Start frontend (separate terminal)
cd frontend
npm install
npm run dev
```

Open:
- Frontend: http://localhost:3000
- API docs: http://localhost:5000/api-docs
- Hangfire: http://localhost:5000/hangfire
- Seq logs: http://localhost:5341
- MinIO console: http://localhost:9001

### Full Docker stack

```bash
cp .env.example .env
# Edit .env

docker compose up -d
```

## Configuration

| Variable | Description |
|---|---|
| `AI_PROVIDER` | `Mock` \| `OpenAI` \| `Anthropic` \| `AzureOpenAI` |
| `OPENAI_API_KEY` | OpenAI API key |
| `ANTHROPIC_API_KEY` | Anthropic API key |
| `AUTH_AUTHORITY` | OIDC authority URL (Entra ID tenant) |
| `POSTGRES_PASSWORD` | PostgreSQL password |
| `ENCRYPTION_KEY` | Base64-encoded 32-byte AES key |
